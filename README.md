# MOVE64 — кандидат исходников для Android

Это **исходный код, не собранный APK**. Flutter SDK отсутствует в среде подготовки, поэтому компиляция и поведение на устройстве не подтверждены.

## Сборка
1. Загрузить содержимое каталога в корень нового GitHub-репозитория.
2. Actions → Build Android APK → Run workflow.
3. Workflow выполняет flutter analyze, затем flutter build apk --release и публикует артефакт MOVE64-APK **только при успешной сборке**.

## Реализовано в этом кандидате
- Deep Indigo; постоянные 8 цветов категорий; обновлённое пустое состояние и состояние завершённого дня.
- Планирование, каталог, избранное, таймер, дневник и обзорная аналитика с кольцевой диаграммой и периодами.
- Защита от копирования дня/недели в себя и копирования результатов; подтверждение удаления.

## Известные ограничения
- Хранилище пока SharedPreferences, не SQLite. Нет транзакций, миграций и резервного копирования.
- Нет системных уведомлений и полноценной модели свободной тренировки.
- Inter задан как fontFamily, но файл шрифта не включён: на Android без установленного Inter используется системный fallback.
- Иконки Material Outline, а не окончательный единый набор Lucide.
- Таймер использует системное время и требует защиты от изменения часов.
- Нет полного набора тестов и независимой проверки UX всех сценариев.

Это промежуточная версия; **не предназначена для публикации в RuStore**.
